# E-Learning รุ่น Next.js / Express / TypeScript

โปรเจกต์นี้ย้ายจากระบบ PHP ในโฟลเดอร์แม่โดยอ้างอิงหน้าจอ ข้อความ และโครงสร้างข้อมูลเดิม ไฟล์ PHP เดิมไม่ได้ถูกแก้ไข

## เริ่มใช้งานบนเครื่องนี้

ต้องมี Node.js และ XAMPP MariaDB ที่ `C:\xampp\mysql\bin` จากนั้นเปิด PowerShell:

```powershell
cd C:\xampp\htdocs\e-learning\same-project-typescript-react-express-nodejs-api
npm run dev
```

เปิด http://localhost:3000 โดย Express API ทำงานที่ http://localhost:4000 หากมี terminal เดิมเปิดเว็บอยู่ ให้หยุดด้วย Ctrl+C ก่อนเริ่มซ้ำเพื่อไม่ให้พอร์ตชนกัน

คำสั่ง `npm run dev` จะเริ่ม MariaDB ที่ `127.0.0.1:3308` โดยใช้โฟลเดอร์ `.local-db` ของโปรเจกต์นี้เท่านั้น ถ้ายังไม่มีฐานข้อมูล `elearning_tsx` สคริปต์จะนำเข้า `database/elearning_db.sql` ครั้งแรก และจะไม่ทับข้อมูลหลังจากนั้น ฐานข้อมูลนี้เป็นสำเนาแยกจากระบบ PHP เดิม การแก้ไขข้อมูลจึงไม่ซิงก์กลับไปยังระบบเดิม

หากย้ายโปรเจกต์หรือยังไม่ได้ติดตั้งแพ็กเกจ ให้รัน `npm install`, `npm install --prefix backend` และ `npm install --prefix frontend` ก่อนใช้งาน คัดลอกไฟล์ SQL ที่ผู้ใช้ให้มาไปไว้ที่ `database/elearning_db.sql` และคัดลอก `backend/.env.example` เป็น `backend/.env` พร้อมตั้ง `JWT_SECRET` เป็นข้อความสุ่มยาวที่เก็บเป็นความลับ หาก XAMPP อยู่ตำแหน่งอื่นให้ตั้งตัวแปร `MYSQL_BIN` เป็นโฟลเดอร์ `mysql/bin` ก่อนรัน

ไฟล์ SQL และข้อมูล MariaDB ภายในเครื่องถูกละเว้นจาก Git เพราะมีข้อมูลผู้ใช้ ไฟล์รูปที่อัปโหลดใหม่เก็บใน `backend/uploads` ส่วนรูปเดิมอ่านจาก `../uploads` และ `../image` โดยไม่แก้ไขไฟล์ต้นฉบับ

## ขอบเขต

มีหน้าแรก คอร์ส ค้นหาและกรองหมวดหมู่ สมัครสมาชิก เข้าสู่ระบบ บทเรียนและความคืบหน้า แบบทดสอบ ประวัติ คะแนน ใบประกาศ PDF โปรไฟล์ การแจ้งเตือน และหน้าจัดการคอร์ส บทเรียนและแบบทดสอบตามสิทธิ์

ข้อมูล SQL ที่ได้รับอ้างถึงรูปปกคอร์สและรูปโปรไฟล์บางไฟล์ที่ไม่มีอยู่ในโฟลเดอร์ไฟล์เดิม จึงแสดงภาพสำรองเหมือนเงื่อนไขของระบบเดิมจนกว่าจะได้รับไฟล์รูปเหล่านั้น ใบประกาศสร้างด้วย PDFKit จึงอาจจัดหน้าไม่ตรงกับ TCPDF ทุกพิกเซล หน้าติดต่อบันทึกข้อความลงตาราง contact_messages จริง และผู้ดูแลระบบอ่านได้ที่ /admin/messages โดยยังไม่มีการส่งอีเมลอัตโนมัติ

## บัญชีทดสอบตามบทบาท

ใช้ปุ่ม **เลือกบทบาททดสอบ** หรือเปิด `/demo-roles` แทนหน้าล็อกอิน/ลงทะเบียน เลือก `sunpavit` สำหรับผู้ดูแลระบบ, บัญชี `teacher_*` สำหรับผู้สอน หรือ `poppapon` / `sunpawit` สำหรับผู้เรียน ระบบจะสร้างเซสชันด้วยสิทธิ์ของบัญชีที่เลือก และสลับบัญชีได้จากเมนู **เปลี่ยนบทบาททดสอบ**

ตั้ง `DEMO_MODE=true` ใน `backend/.env` เพื่อเปิดการเลือกบัญชีโดยไม่ใช้รหัสผ่าน บัญชีทดสอบใช้ข้อมูลในฐานข้อมูลสำเนา `elearning_tsx` การเรียนและการแก้ข้อมูลจะถูกบันทึกในสำเนานี้


## ข้อความติดต่อ

ผู้เข้าชม ผู้เรียน และผู้สอนส่งข้อความได้ที่ `/contact` ข้อมูลจะถูกบันทึกลงฐานข้อมูลก่อนแสดงผลสำเร็จ ผู้ดูแลระบบมีเมนู **ข้อความติดต่อ** ที่ `/admin/messages` สำหรับค้นหา เปิดอ่าน กรองสถานะ และทำเครื่องหมายว่าดำเนินการแล้ว หน้าและ API นี้ตรวจสิทธิ์ admin ทั้งคู่ ตาราง `contact_messages` สร้างเพิ่มอัตโนมัติเมื่อ backend เริ่มทำงาน โดยไม่ลบข้อมูลเดิม

## โหมดสว่างและโหมดมืด

สลับธีมด้วยไอคอนพระจันทร์/ดวงอาทิตย์บนเมนูได้ทั้งหน้าจอคอมพิวเตอร์และมือถือ ธีมที่เลือกบันทึกไว้ในเบราว์เซอร์และใช้ต่อเมื่อเปลี่ยนหน้าหรือเปิดใหม่ หากยังไม่ได้เลือก เว็บจะใช้ค่าตามระบบของอุปกรณ์

## หน้าเว็บ Next.js

หน้าบ้านใช้ App Router โดยแต่ละ URL มีไฟล์ `page.tsx` ของตัวเองใน `frontend/src/app` ใช้ `next/link` สำหรับการนำทาง และเก็บสถานะบัญชีใน layout ร่วมกัน

| หน้า | URL | ไฟล์หน้าจอ |
| --- | --- | --- |
| คอร์สทั้งหมด | `/courses` | `frontend/src/app/courses/page.tsx` |
| รายละเอียดคอร์ส | `/courses/16` | `frontend/src/app/courses/[id]/page.tsx` |
| ติดต่อ | `/contact` | `frontend/src/app/contact/page.tsx` |
| โปรไฟล์ | `/profile` | `frontend/src/app/profile/page.tsx` |
| ข้อความของผู้ดูแล | `/admin/messages` | `frontend/src/app/admin/messages/page.tsx` |

URL ของ Next.js ไม่ต้องมีนามสกุลไฟล์ `.tsx` ชื่อ URL เก่าใช้เฉพาะ redirect ใน `next.config.ts` สำหรับ bookmark เดิมเท่านั้น ไม่มีการประมวลผล PHP ในโปรเจกต์ใหม่นี้
